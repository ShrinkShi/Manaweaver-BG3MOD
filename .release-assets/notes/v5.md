# v5 — Manaweaver Subclass / 魔能术士子职业

## 中文
首次将系统重构为真正的邪术师子职业“魔能术士（Manaweaver）”。加入魔能诅咒、魔能之心 I/II/III、魔能精通、死亡魔爆链、复活机制，并修复追袭魔爆，使额外射线可以与其他射线攻击同一目标。

**推荐使用最新 v8。**

## English
Rebuilt the system as a true Warlock subclass: **Manaweaver**. Added Mana Curse, Mana Heart I/II/III, Mana Mastery, death-triggered Eldritch Blast chains, revival mechanics, and fixed Pursuing Blast so the extra beam can target the same creature as other beams.

**Use v8 for the current build.**
