# v6 — Manaweaver Progression Rework / 魔能术士成长重构

## 中文
将魔能术士成长线与原版邪术师进一步隔离：不再获得魔契三选一或原版魔能祈唤，只能选择专属的9项魔能被动。移除术法点体系，并重构资源/升级逻辑。

**推荐使用最新 v8。**

## English
Further isolated Manaweaver progression from vanilla Warlock: no Pact Boon selection and no vanilla Eldritch Invocation selection; the subclass instead uses its own nine Mana passives. Removed the Sorcery Point experiment and reworked progression/resource logic.

**Use v8 for the current build.**
