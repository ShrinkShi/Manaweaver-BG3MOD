# v3 — Progressive Eldritch Blast / 渐进魔能爆

## 中文
加入按等级与射线序号变化的魔能爆伤害实验，并尝试同一次施法中不同射线使用不同伤害。非原生 d14/d16 以 `1d12+1` / `1d12+2` 的等期望值形式实现。

这是历史实验版本。**推荐使用最新 v8。**

## English
Added experimental level- and beam-index-based Eldritch Blast damage, including different damage profiles for individual beams in the same cast. Non-native d14/d16 were represented as equal-mean `1d12+1` / `1d12+2`.

Historical experimental build. **Use v8 for the current build.**
