# v1 — Eldritch Blast Prototype / 魔能爆原型

## 中文
项目的最初原型。尝试通过静态 `LevelMap` 覆盖，将魔能爆调整为每2个角色等级增加1束，11–12级达到6束，并为更高等级上限预留6束封顶。

这是历史实验版本；静态覆盖路线后来被 v2 的 Script Extender 运行时修改方案取代。**推荐使用最新 v8。**

## English
The original prototype. It attempted to override the static `LevelMap` so Eldritch Blast gained one beam every two character levels, reaching six beams at levels 11–12 and remaining capped at six for higher level-cap mods.

This is a historical experimental build; the static override approach was replaced by the Script Extender runtime implementation in v2. **Use v8 for the current build.**
