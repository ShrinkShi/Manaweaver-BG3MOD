# v4 — Eldritch Blast Specialization / 魔爆专精

## 中文
从单纯修改魔能爆数值扩展为“魔爆专精”体系：基础束数回归1/2/3束，加入多种魔爆被动、追袭魔爆、命中/击杀联动、虚弱与终极魔爆等机制。此版本曾实验性使用术法点资源，后续已推翻。

**推荐使用最新 v8。**

## English
Expanded the project from raw Eldritch Blast tuning into an Eldritch Blast specialization system: base 1/2/3-beam progression, multiple blast passives, Pursuing Blast, hit/kill interactions, weakening effects, and Ultimate Blast. This build experimentally used Sorcery Points, which was removed later.

**Use v8 for the current build.**
