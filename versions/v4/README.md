# v4 — Eldritch Blast Specialization / 魔爆专精

## 中文
将基础魔能爆改为总角色等级1–4级1束、5–8级2束、9–12级3束，并引入完整的“魔爆被动”体系。新增：术法魔爆、噬法魔爆、汲魂魔爆、追袭魔爆、虚弱魔爆、终极魔爆。

v4 为所有邪术师额外提供1–12级每级一次祈唤选择，并尝试引入术法点资源：术法魔爆通过三个开关消耗术法点增伤；噬法魔爆击杀返还术法点。追袭魔爆额外+1束；虚弱魔爆随机降低属性；终极魔爆在同一目标一回合遭到第4束命中时触发4米力场爆炸。

该版本仍属于全邪术师强化实验，术法点设计和通用祈唤注入在后续版本被推翻。

## English
Resets base Eldritch Blast scaling to 1 beam at total character levels 1–4, 2 at 5–8, and 3 at 9–12, then introduces a full Eldritch Blast passive system: Metamagic Blast, Spell-Eating Blast, Soul-Draining Blast, Pursuit Blast, Weakening Blast and Ultimate Blast.

v4 granted every Warlock one extra invocation choice at every level from 1–12 and experimented with Sorcery Points as a resource. Pursuit Blast added one beam, Weakening Blast reduced random ability scores, and Ultimate Blast triggered a 4m Force explosion when a target received its fourth Eldritch Blast hit in the same round.

This was still a global Warlock enhancement experiment. The Sorcery Point design and global invocation injection were replaced in later versions.
