# v5 — Manaweaver Subclass / 魔能术士子职业

## 中文
v5 将 MOD 从“所有邪术师的全局强化”重构为真正的邪术师子职业：**魔能术士（Manaweaver）**。新增魔爆被动只对该子职业开放，并将额外被动选择改为1、3、5、6、8、9、10、11、12级，共9次。

核心职业成长：
- 1级：魔能诅咒（最大生命-50%、AC+1）与魔能之心（死亡时向5米内生物释放当前束量的魔爆，不分敌我）。
- 5级：魔能诅咒II（仍减半生命、失去AC+1）与魔能之心II（死亡魔爆击杀后递归追加射线；有追袭魔爆时每次击杀追加2束）。
- 11级：魔能精通（解除诅咒、魅力调整值加入AC、魔爆命中获得临时生命、Miss获得附赠动作、借机攻击改为完整魔能爆）与魔能之心III（死亡爆发击杀后复活至1HP，额外击杀提供24点临时生命，并强化复活后的下一次戏法暴击阈值）。

追袭魔爆在本版修正为可与原射线攻击同一目标。v5 仍保留术法点方案，随后在 v6 移除。

## English
v5 turns the project from a global Warlock enhancement into a true Warlock subclass: **Manaweaver**. The new Eldritch Blast passives become subclass-exclusive, with extra passive choices at Warlock levels 1, 3, 5, 6, 8, 9, 10, 11 and 12 — nine selections total.

Core progression:
- Level 1: Mana Curse (maximum HP -50%, AC +1) and Mana Heart (on death, fire the current Eldritch Blast beam count at creatures within 5m, friend or foe).
- Level 5: Mana Curse II (HP remains halved, AC bonus removed) and Mana Heart II (death-blast kills recursively add more rays; Pursuit Blast makes each kill add two).
- Level 11: Mana Mastery (curse removed, Charisma modifier added to AC, temporary HP on Eldritch Blast hits, bonus actions on misses, opportunity attacks replaced with a full Eldritch Blast) and Mana Heart III (revive at 1 HP after at least one death-blast kill, gain 24 temporary HP per additional kill, and improve the next cantrip's critical threshold).

Pursuit Blast is fixed here so its extra beam can target the same creature as the other beams. v5 still used Sorcery Points, which were removed in v6.
